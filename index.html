Why you need this

AI can clone your voice from a few seconds of audio. Scammers call families pretending to be a loved one in trouble.

  • 🔒
    Voice cloning needs only 3 seconds of any public video, voicemail, or social clip of you to create a convincing fake.
  • 🔈
    The "grandparent scam" is exploding: callers impersonate a child/grandchild asking for urgent money. AI makes the voice sound exactly right.
  • 👤
    Anyone can be targeted — the young, old, everyone. The best defense has nothing to do with tech.
  • ✅
    Your family safe word is the fix. A word only your family knows defeats any audio clone, no matter how perfect.

2-minute setup

Step 1 — Open the Safe Codes tab and create your family code word.
Step 2 — Share the code word privately with family (never by text/email/VoIP if possible — tell them in person or over a separate channel).
Step 3 — Agree: anyone asking for money/help over the phone must say the code word first. No code word = no deal. Ever.
Step 4 — Run the Detection Quiz with the whole family, and print wallet cards & posters for the elders.
⚡ Golden rule: Trust the code word, not the voice or the number. Numbers can be spoofed, voices can be cloned — a secret code word cannot.

  • Rotate the code occasionally, e.g. every 6 months.
